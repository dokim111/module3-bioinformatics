추가 실험 원본 보존 별첨

기존 원본 묶음에 병합하기 위한 추가 자료이며, 기존 파일은 수정하지 않았다.
추가 SVG 11개와 각 조건에 대응하는 입력 FASTA 11개를 원본 바이트 그대로
보존했다. 파일 이름과 조건의 대응은 source_metadata/additional/
file_condition_mapping.csv 및 같은 이름의 JSON에 있다.

포함한 조건: 랫을 추가한 CYTB DNA 1개, 외군 제외 DNA 2개,
코끼리·아르마딜로 대체 외군 DNA 4개, 아르마딜로 외군 단백질 2개,
원래 주머니쥐 외군 단백질 2개. 총 11개이다.
원래 15개 SVG 및 해당 입력은 기존 묶음에 그대로 유지한다.

SVG 내부의 종 이름은 각 입력의 종 집합과 일치하는지 확인했다.
유전자·자료형·외군 등의 조건 이름은 사용자가 제공한 파일명과 최종 대응
정보에 따른 것이다. SVG만으로 실제 정렬 방법·계통추론법·거리모형·선택
위치·bootstrap 반복 수를 모두 확인할 수 없으므로 해당 항목은 미확인으로
표시했다. 숫자 지지도의 존재를 bootstrap 설정 로그로 취급하지 않았다.

source_metadata/additional/의 입력 provenance·검증 파일에는 입력 준비 당시
계획이 포함될 수 있다. 이는 서열 출처와 입력 동일성 확인 자료이며 실제
프로그램 실행 로그를 뜻하지 않는다. 입력 준비 시점의 미수행 상태를 적은
문장 역시 그 시점의 기록이다. 사용자 업로드 SVG는 그 뒤 제공된 결과다.

새 외군·랫의 NCBI 원문 GenBank 3개를 추가했고, 기존 내군·주머니쥐의
GenBank 9개는 기존 묶음에 있어 중복 저장하지 않았다. 그 의존 관계는
existing_source_dependencies.json에 기록했다. 다운로드·추출 및 단백질
주석 대조에 관한 저장된 출처 기록을 함께 보존했다.

이 staging 작업은 파일 복사와 동일성·종 이름 대조만 수행했다.
새 정렬·계통수 추론·이미지 재도식화는 수행하지 않았다.
SHA256_extension.csv는 현재 파일의 동일성 확인값이며 실제 분석을 수행한
사람이나 실행 일시를 증명하는 기록은 아니다.
