# CYTB 41종 참고 분석

이 결과는 제출용 메인 보고서에 포함하지 않은 참고 자료입니다.
영장목·설치목·우제목(고래류 포함)·식육목 각 10종과 버지니아주머니쥐 외군 1종을 사용했습니다.

- [Phylo.io 원본 SVG](PhyloIO_Tree_CYTB_41species.svg)
- [정렬 전 입력 FASTA](CYTB_41species_input.fasta)
- [41종 accession 및 CYTB 좌표](accessions.csv)
- [실행 조건과 해석 요약](analysis_summary.json)

실행자는 MAFFT 온라인 정렬 후 NJ, Jukes–Cantor, Conserved sites,
bootstrap 1,000회로 분석했음을 확인했습니다. 이는 실행자의 확인 기록이며,
SVG에서 설정을 복원한 것은 아닙니다. 정렬 완료 FASTA와 실행 로그는 현재 보관 자료에 없습니다.

주머니쥐를 외군으로 읽으면 식육목 10종은 지지도 77, 우제목·고래류 10종은 49로 묶였습니다.
영장목 10종, 설치목 10종, 두 목을 합친 20종의 집합은 나타나지 않았습니다.
사람·침팬지는 70, 생쥐·시궁쥐는 99로 묶였습니다.
따라서 이 결과를 영장목과 설치목 전체의 가까운 관계를 확인한 근거로 사용하지 않았습니다.

원본 SVG는 업로드된 바이트 그대로 보관했습니다. 표시 뿌리가 주머니쥐에 있지 않으므로
그림의 위아래 순서로 분기 방향을 판단하면 안 됩니다. 위 해석은 원본 연결을
주머니쥐 기준으로 읽은 결과이며, 새로운 계통수 추론을 실행한 것이 아닙니다.
원본의 긴 FASTA 설명 때문에 오른쪽 라벨이 화면 밖으로 나갈 수 있습니다.
